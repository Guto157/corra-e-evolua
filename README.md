# Corra e Evolua

Jogo idle de corrida lateral automática. O personagem corre sozinho; o jogador acompanha a distância, administra energia e investe as recompensas em melhorias.

## Primeira versão
- Escolha entre personagem masculino e feminino.
- Corrida automática em cenário lateral.
- Energia, distância, velocidade e recorde.
- Moedas, experiência e níveis.
- Melhorias de energia, velocidade e resistência.
- Salvamento local automático no navegador.
- Estrutura modular para futuras atualizações.

## Testar
Abra **https://Guto157.github.io/corra-e-evolua/** depois de ativar o GitHub Pages em Settings → Pages → Deploy from a branch → main → /(root).

## Estrutura
- `core/`: regras centrais, jogador, economia e salvamento.
- `js/`: interface e renderização.
- `updates/`: módulos opcionais de futuras atualizações.
- `css/`: aparência responsiva.

## Observações
Esta é a primeira versão jogável de navegador. Anúncios, compras premium, veículos, equipamentos e sincronização em nuvem serão integrados em etapas posteriores, depois da validação do núcleo.
